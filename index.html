Let the agent structure the mess.

Security Ledger is not the tutor. It is the persistent staging surface and technical memory behind the tutor.

  1. Drop raw material into Inbox: narration, pasted notes, URLs, screenshots, or files.
  2. In a WebMCP-enabled agent session, ask the agent to inspect the inbox and turn useful material into structured notes, sources, challenges, and solve records.
  3. Use the same ledger during practice. The agent can retrieve prior concepts and patterns, but should stay at high-level guidance rather than solving the challenge for you.
